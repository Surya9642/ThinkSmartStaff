# ThinkSmartStaff Frontend

A React, TypeScript and Vite frontend for ThinkSmartStaff, an IT staffing and software solutions company.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Features

- Separate journeys for job seekers, companies hiring technology talent, and software clients.
- Local demo job listings with instant search and filters.
- Job detail and client-side application flows.
- Staffing, project and contact inquiry forms with frontend-only confirmation.
- Technology categories, service pages and responsive navigation.
- Animated Three.js globe with a lightweight visual fallback.

All roles, statistics and form flows are demonstration content. Forms do not send or store data.
